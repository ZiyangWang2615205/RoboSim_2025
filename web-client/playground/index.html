Clear Scene?

This will remove all boxes from the current scene. This action cannot be undone.

☰ Controls

Selected Box: None

Insert Mode: Off

Camera Controls

To zoom, use the scroll wheel.

To pan, hold right mouse and move.

To rotate, hold left mouse and move.

Box Controls

Select Box: Mouse Click

Add Box: Add Box or Enter

Remove Box: Remove Box or Shift + Enter

Move Box:

  • Up Arrow moves North
  • Down Arrow moves South
  • Right Arrow moves East
  • Left Arrow moves West

Leg Control:

  • Displace/Withdraw: Displace/Withdraw or o
  • Extend/Retract: Extend/Retract or u

Insert Mode

Hold Space to enter Insert Mode. While held:

  • Left click to place a box at the cursor
  • Right click to remove the targeted box

Camera controls are locked during Insert Mode.

Forklift Mode

In Forklift Mode, you can move a stack of boxes by selecting the bottom box (box on the ground), simulating a forklift. This makes it easier to build configurations of boxes.

Note: When building algorithms to move boxes, you cannot move stacks of boxes. This is purely to help with building scenes in the Playground.

Toggle with Shift + F

This feature is unavailable for Type 2 boxes.

Rules & Restrictions

  • You cannot move a box if it has boxes on top of it (except if moving the bottom box of a stack in Forklift Mode)
  • You cannot move a box if the height difference between the current box position and new box position is greater than 1.
  • You cannot remove a box if it has boxes on top of it.

Scene Controls

Clear Scene: Removes all boxes. Shift + C

Save Scene: Saves the scene as a .json file. Shift + S

Load Scene: Loads and displays an existing saved scene. Shift + L

Reset State: Resets the start and end states for a custom scenario. Shift + R

Custom Scenarios

You can create custom scenarios from the current scene using the Save Scene as Scenario button.

  • Set the number of target boxes you want to move.
  • For each target, enter the box ID. The current location will be shown automatically.
  • Provide the target location (x, y, z) for each box.
  • Name the scenario and download it.

You can load a custom scenario in your algorithm's Python file in order to test your algorithm on it.

Box Type Controls

You can switch between the 2 box types in the Playground by using the Switch to Type ... button, or by toggling with Shift + T
The default is Type 1.

Scenarios

A scene is a layout of boxes. A scenario adds target locations for selected boxes, creating a challenge for your algorithm to solve. Use the scenario wizard to create scenarios from the current scene.
